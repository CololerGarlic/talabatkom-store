# متجر الدكان (Arap Bakkali) - Next.js + Tailwind Storefront

مشروع متجر إلكتروني متكامل وخفيف مصمم خصيصاً للبقالات ومحلات الأحياء، ليعمل بسرعة فائقة وتصميم أكثر نظافة واحترافية من Take App مع ربط مباشر بطلبات واتساب وتوافق كامل للاستضافة المجانية على **Vercel**.

---

## 🌟 أبرز مميزات المتجر والتصميم

1. **شريط الأقسام العلوي (Categories Ribbon):**
   * شريط تمرير سلس لليمين واليسار (أزرار تصفح + لمس وسحب على الهواتف).
   * أيقونات مخصصة وأسماء الأقسام مع شارة مميزة لقسم "العروض".
2. **قسم المنتجات المخفضة (العروض والتخفيضات):**
   * يقع مباشرة تحت شريط الأقسام، ويعرض المنتجات المخفضة بأسعار مميزة وشارات خصم.
3. **صفحات الأقسام المستقلة:**
   * كل قسم له صفحته المستقلة (`/category/spices`، `/category/frozen-dairy`، إلخ) مع خيارات الترتيب والبحث.
4. **سلة التسوق واحتساب رسوم التوصيل (100 TL):**
   * سلة تسوق جانبية ديناميكية.
   * توضيح صريح لرسوم التوصيل الثابتة (**+100 ليرة**).
   * إجمالي الفاتورة = المجموع الفرعي + 100 ليرة.
5. **الطلب المباشر عبر واتساب:**
   * بمجرد إدخال العميل لاسمه، هاتفه، وعنوانه والنقر على الزر الرئيسي، يتم إنشاء رسالة واتساب منسقة ومفصلة ترسل مباشرة إلى هاتف المتجر.

## ✅ التحقق من قائمة المهام الـ 20 (The 20 Checklist Requirements)

1. **Privacy Policy Page:** صفحة سياسة الخصوصية متوافقة مع قانون حماية البيانات التركي (`/privacy`).
2. **Terms and Conditions:** صفحة الشروط والأحكام وسياسة توصيل المنتجات الغذائية والدفع عند الاستلام (`/terms`).
3. **Force HTTPS:** إعدادات أمان مشددة في `vercel.json` تفرض بروتوكول HTTPS مع `Strict-Transport-Security`.
4. **Cookie Consent Banner:** شريط موافقة على ملفات تعريف الارتباط متجاوب مع حفظ الاختيار في `localStorage`.
5. **Meta Titles and Descriptions:** بطاقات SEO ديناميكية وافتراضية لكل صفحة وقسم.
6. **Social Preview Image:** صورة مشاركة وسائل التواصل الاجتماعي مجهزة في `public/og-image.svg`.
7. **Favicon:** أيقونة متجر حديثة مجهزة في `public/favicon.svg`.
8. **Sitemap and Robots.txt:** خريطة موقع كاملة `sitemap.xml` وملف `robots.txt` لتوجيه محركات البحث.
9. **Alt Text on Images:** نصوص بديلة عربية دقيقة لجميع صور المنتجات والأقسام.
10. **Compress Images:** استدعاء الصور عبر وسائط خفيفة مع lazy loading ودعم تحسينات Next.js Image.
11. **Page Load Speeds:** كود خفيف بدون مكتبات زائدة وخطوط مسبقة التحميل لضمان سرعة فائقة.
12. **Color Contrast:** درجات ألوان متوافقة تماماً مع معايير الوصول (WCAG) بنسب تباين عالية للقراءة.
13. **Mobile Friendly:** عرض 3 منتجات في الصف الواحد على الهواتف مع أزرار لمس مريحة وشريط سلة عائم.
14. **Custom 404 Page:** صفحة خطأ 404 احترافية مع أزرار للعودة للرئيسية (`/404`).
15. **Zero Broken Links:** جميع الروابط الداخلية والخارجية وروابط الأقسام مفحوصة ومؤكدة.
16. **Form Validation:** تحقق دقيق من صحة الاسم، رقم الهاتف، وعنوان التوصيل قبل إرسال الطلب.
17. **Remove Secrets off Frontend:** استخدام متغيرات بيئة عامة نظيفة (`NEXT_PUBLIC_WHATSAPP_NUMBER`) بدون كشف أي مفاتيح سرية.
18. **Spam Protection:** حقل وهمي (Honeypot) خفي وفحص زمني لمنع روبوتات الإسبام والطلبات الآلية.
19. **Analytics Setup:** مكون مهيأ لربط Google Analytics 4 أو تحليلات Plausible بسهولة.
20. **One Clear Call to Action:** زر واتساب رئيسي أخضر واضح ومميز طوال مسار العميل.

## 🚀 طريقة التشغيل والرفع على Vercel (خطوة بخطوة)

### الطريقة 1: الرفع المباشر عبر Vercel و GitHub (أسهل طريقة)

1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub (مثلاً: `al-dukan-store`).
2. ارفع مجلد المشروع إليه:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Al-Dukan Store"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/al-dukan-store.git
   git push -u origin main
   ```
3. اذهب إلى [Vercel.com](https://vercel.com) وسجل دخول بحساب GitHub.
4. اضغط **Add New Project** واختر المستودع `al-dukan-store`.
5. في قسم **Environment Variables**، يمكنك وضع رقم الهاتف:
   * `NEXT_PUBLIC_WHATSAPP_NUMBER`: ضع رقم هاتف والدك (مثال: `905318182288`)
6. اضغط **Deploy**. خلال دقيقة واحدة سيكون موقعك متاحاً برابط رسمي وسريع ومجاني!

### الطريقة 2: المعاينة الفورية المستقلة (Offline / Single-File)

يمكنك ببساطة فتح الملف `public/standalone.html` في أي متصفح (كروم، سفاري) بدون الحاجة لتثبيت أي برامج أو خوادم لمعاينة وتجربة المتجر والسلة والواتساب فوراً!
